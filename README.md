# Εξοδούχοι

Μικρή εφαρμογή για να γράφεις τη λίστα εξόδων του θαλάμου (ΔΝ / Ε / —) και να τη στέλνεις σε Viber/WhatsApp.
Λειτουργεί εκτός σύνδεσης, χωρίς server· τα δεδομένα μένουν στο κινητό.

## Android (APK)
- Κάθε push στο `main` χτίζει το APK μέσω GitHub Actions και το ανεβάζει στα **Releases** (`Exodouxoi.apk`).
- Εγκατάσταση: κατέβασε το APK στο κινητό, άνοιξέ το, επίτρεψε «εγκατάσταση από άγνωστες πηγές».
- Ενημέρωση: εγκατάσταση της νέας έκδοσης πάνω από την παλιά· τα δεδομένα μένουν (ίδιο κλειδί υπογραφής, `android/keystore/`).
- Ο κώδικας της εφαρμογής είναι το `android/app/src/main/assets/index.html` (ανοίγει και σκέτο σε browser).

## iPhone (Scriptable)
1. Εγκατάσταση του δωρεάν **Scriptable** από το App Store.
2. Αντιγραφή όλου του `scriptable/Exodouxoi.js`.
3. Στο Scriptable: **+**, επικόλληση, όνομα «Εξοδούχοι».

## Πώς δουλεύει
- Κάθε μέρα όλοι ξεκινούν κίτρινοι με πρόταση από τις προηγούμενες μέρες· επιβεβαιώνεις τον καθένα με ✓ ή αλλάζεις.
- ✉️ Μήνυμα: επιλέγεις μέρες, Αποστολή ή Αντιγραφή· οι μέρες κλειδώνουν ως τελικές.
- Περασμένες/κλειδωμένες μέρες δείχνουν μόνο την τελική λίστα (✎ Αλλαγή για διόρθωση).
- 🚫 Καμία έξοδος για μέρες που δεν βγαίνει κανείς (δεν επηρεάζουν τις προτάσεις).
- 📥 Εισαγωγή κειμένου: επικόλληση παλιού μηνύματος για να μπει στο ιστορικό.

> Το κλειδί υπογραφής είναι μέσα στο repo για απλότητα — κράτα το repo ιδιωτικό.
